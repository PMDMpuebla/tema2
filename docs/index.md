# Programación Multimedia y Dispositivos Móviles - Tema 2

## El lenguaje de Programación Kotlin

En este tema se abordará el desarrollo de aplicaciones usando el lenguaje Kotlin; centrándonos en la sintaxis y características del lenguaje, así como una introducción a su uso en Android.

## Objetivos

Los Objetivos de este tema son:

* Conocer la diferencia entre Kotlin y Java, así como sus ventajas y desventajas.
* Comprender la sintaxis básica de Kotlin y cómo se aplica en el desarrollo de aplicaciones Android.
* Aprender las diferentes características de Kotlin que facilitan el desarrollo de aplicaciones móviles.
* Comprender el uso de Kotlin en el contexto de Android, incluyendo la interoperabilidad con Java y las bibliotecas específicas de Android.

## Contenido

El contenido de este tema se divide en las siguientes secciones:

* Introducción a Kotlin.
* Sintaxis básica de Kotlin.
* Características avanzadas de Kotlin.
* Orientación a objetos en Kotlin.
* Funciones y expresiones lambda.
* Colecciones y manejo de datos en Kotlin.
* Interoperabilidad entre Kotlin y Java.
* Uso de Kotlin en el desarrollo de aplicaciones Android.
