# Introducción a Kotlin en Android

Kotlin es un lenguaje de programación moderno y conciso que se ha convertido en el lenguaje preferido para el desarrollo de aplicaciones Android. Desde 2017, Google ha anunciado oficialmente el soporte de Kotlin para Android, lo que significa que los desarrolladores pueden utilizar Kotlin para crear aplicaciones Android de manera eficiente y con menos código.

Es por ello que en este curso, aprenderemos a utilizar Kotlin para desarrollar aplicaciones Android, aprovechando sus características y ventajas para crear aplicaciones más robustas y mantenibles.

Hasta ahora hemos visto kotlin como un lenguaje de programación independiente, pero en este curso nos centraremos en su uso dentro del ecosistema Android. Aprenderemos a crear interfaces de usuario, manejar eventos, trabajar con bases de datos y mucho más, todo utilizando Kotlin.

No existe una única forma de programar en Android, pero Kotlin nos ofrece una sintaxis más clara y concisa que Java, lo que nos permite escribir código más legible y fácil de mantener. Además, Kotlin es totalmente interoperable con Java, lo que significa que podemos utilizar bibliotecas y frameworks existentes en Java sin problemas.

También podemos utilizar código Java dentro de un fichero Kotlin:

```kotlin
fun main() {
    val lista = ArrayList<String>()
    lista.add("Hola")
    println(lista[0])
}
```

Habrás podido notar que hemos utilizado la clase `ArrayList` de Java dentro de un archivo Kotlin. Esto demuestra la interoperabilidad entre ambos lenguajes y nos permite aprovechar las bibliotecas y frameworks existentes en Java mientras escribimos nuestro código en Kotlin.
